MindMate AI - PWA starter demo

Files:
- index.html: responsive front-end
- manifest.webmanifest: installable web-app metadata
- sw.js: basic offline cache
- icon.svg: app icon

Important:
This is a front-end demonstration only. Chat replies are prewritten, not AI.
Journal text is only previewed in the current page and is not saved or sent.
Do not collect sensitive data or publish this as a therapy/clinical service.
Before adding real AI, accounts, or saved journals, add a secure server-side
backend, privacy policy, age-appropriate safeguards, crisis-support handling,
security review, and qualified professional review.

To test:
Serve these files over HTTPS or localhost. A PWA service worker will not
install from an ordinary file:// preview. Deploy only on a host whose terms
allow your intended use. Free hosting has quotas and can change.
